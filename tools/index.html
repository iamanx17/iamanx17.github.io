cURL

Turn a request you already have into code you can run.

  • cURL → Code Converter Convert a cURL command into runnable code in nine languages.
  • cURL → JavaScript Browser-ready fetch() with async/await and a status check.
  • cURL → Python Python 3 script using requests, with a timeout and raise_for_status().
  • cURL → Node.js Node 18+ script using the built-in global fetch — no packages.
  • cURL → Axios Axios request config for Node or the browser, with try/catch.
  • cURL → Go Idiomatic net/http with a client timeout and deferred body close.
  • cURL → Java JDK 11+ java.net.http HttpClient with no external dependencies.
  • cURL → PHP PHP using the built-in cURL extension, closest to the original command.
  • cURL → C# C# HttpClient with an async Main and a status check.
  • cURL → Ruby Ruby standard library Net::HTTP, TLS aware.

JSON

Read, check, compare and generate types from JSON payloads.

  • JSON Formatter Pretty-print or minify JSON, with optional key sorting.
  • JSON Validator Check whether JSON is valid and see exactly where it breaks.
  • JSON Diff Compare two JSON documents key by key.
  • JSON → TypeScript Generate TypeScript interfaces from a JSON sample.
  • JSON → Zod Generate a Zod schema from a JSON sample.
  • JSON → Pydantic Generate Pydantic v2 models from a JSON sample.

Auth

Tokens, encodings and headers — decoded without leaving the page.

  • JWT Decoder Decode the header and payload of a JSON Web Token.
  • JWT Expiry Checker See whether a JWT is expired, not yet valid, or still good.
  • Base64 Encoder / Decoder Encode or decode Base64 and Base64URL, Unicode-safe.
  • URL Encoder / Decoder Percent-encode or decode text for use in URLs.
  • Basic Auth Generator Build or read back an HTTP Basic Authorization header.

API

Compose, inspect and understand HTTP requests and responses.

  • HTTP Request Builder Build a request from parts and export it as cURL or code.
  • HTTP Status Lookup Look up an HTTP status code by number or keyword.
  • HTTP Header Parser Turn a raw header block into a table and a JSON object.
  • URL Parser Break a URL into its parts and list its query parameters.
  • Query String Parser Convert a query string to JSON, or JSON back to a query string.
  • HTTP Response Formatter Split a raw HTTP response into status, headers and a pretty body.

Webhooks

Inspect payloads, generate signatures and test your endpoint.

  • Webhook Payload Formatter Pretty-print a webhook payload and summarise its event fields.
  • Webhook Signature Generator Build a provider-style webhook signature header from a payload and secret.
  • HMAC Generator Compute an HMAC digest of any message with any supported hash.
  • Webhook Tester Send a signed test webhook from your browser and read the response.

Utilities

The small lookups that interrupt everything else.

  • UUID Generator Generate v4 or time-ordered v7 UUIDs in bulk.
  • Regex Tester Test a regular expression and inspect every match and capture group.
  • Unix Timestamp Converter Convert between Unix timestamps, ISO 8601 and human dates.
