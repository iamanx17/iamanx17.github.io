Running the generated Ruby code

  • No gems required. net/http, uri and json all ship with Ruby.
  • use_ssl must be set before the request. Assigning it after start raises. The generated code sets it from the URL scheme immediately after building the client.
  • Query strings survive. Passing the URI object to the request class keeps the query intact; passing url.path instead — a common shortcut — silently drops it.
  • Net::HTTP does not raise on 4xx or 5xx. Check response.code, or call response.value to raise.
  • Timeouts. read_timeout is set; add open_timeout if connecting is also a risk.
  • Faraday or HTTParty are worth the dependency once you need retries, middleware or a shared connection.

What gets converted

The parser reads the method, URL and query string, every -H header, cookies and user agent, -u and --oauth2-bearer credentials, all the -d body variants including --data-urlencode and --json, -G, and multipart -F uploads. Flags that only affect the terminal, such as -s or -v, are ignored; flags with no code equivalent are reported above the output rather than dropped silently.
