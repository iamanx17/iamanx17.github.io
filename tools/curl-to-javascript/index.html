Running the generated JavaScript code

  • No dependency. fetch is built into every current browser. The snippet uses top-level await, so run it inside an async function or an ES module.
  • fetch does not throw on 4xx or 5xx. A 500 still resolves the promise, which is why the generated code checks response.ok explicitly. Removing that check is the single most common cause of silent API failures.
  • CORS applies in the browser. cURL ignores the same-origin policy; your page does not. If the API does not send Access-Control-Allow-Origin, the request must go through your own backend.
  • Do not ship secrets. An Authorization header in browser JavaScript is readable by anyone who opens DevTools. Keep tokens on a server and proxy the call.
  • Timeouts are opt-in. fetch has no default timeout. Add signal: AbortSignal.timeout(30_000) to the options object if you need one.

What gets converted

The parser reads the method, URL and query string, every -H header, cookies and user agent, -u and --oauth2-bearer credentials, all the -d body variants including --data-urlencode and --json, -G, and multipart -F uploads. Flags that only affect the terminal, such as -s or -v, are ignored; flags with no code equivalent are reported above the output rather than dropped silently.

The full option table, worked examples and answers to common problems are on the main converter page, which offers every language in one place.
