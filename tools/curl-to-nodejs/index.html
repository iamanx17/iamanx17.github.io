Running the generated Node.js code

  • Node 18 or newer. fetch, FormData and Blob are global from Node 18. On Node 16 install undici and import them from it.
  • Exit code. The snippet sets process.exitCode = 1 on failure rather than calling process.exit(), so pending writes to stdout still flush — this matters in CI.
  • No CORS, no cookie jar. Server-side fetch skips the same-origin policy, and it does not persist cookies between calls. If the API needs a session cookie you must forward it yourself.
  • Proxies are not automatic. Node's fetch ignores HTTP_PROXY. Behind a corporate proxy, set a ProxyAgent from undici as the dispatcher.
  • Keep secrets in the environment. Replace a pasted token with process.env.API_TOKEN before committing the file.

What gets converted

The parser reads the method, URL and query string, every -H header, cookies and user agent, -u and --oauth2-bearer credentials, all the -d body variants including --data-urlencode and --json, -G, and multipart -F uploads. Flags that only affect the terminal, such as -s or -v, are ignored; flags with no code equivalent are reported above the output rather than dropped silently.
